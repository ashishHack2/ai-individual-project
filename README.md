# Vite React App

A small Vite + React starter application.

## Overview

This repository contains a lightweight React app scaffolded with Vite. It includes a minimal component structure and CSS files to get started quickly.

## Prerequisites

- Node.js 14+ (LTS recommended)
- npm, yarn, or pnpm

(Commands below use `npm` — on Windows use PowerShell or your preferred shell.)

## Install

```powershell
npm install
```

## Development

Start the dev server:

```powershell
npm run dev
```

Open the URL printed by Vite (usually http://localhost:5173).

## Build

Create a production build:

```powershell
npm run build
```

Preview the production build locally:

```powershell
npm run preview
```

## Typical NPM scripts

These are the common scripts expected in `package.json` for a Vite project:

- `dev`: `vite`
- `build`: `vite build`
- `preview`: `vite preview`

If your `package.json` differs, adjust the commands accordingly.

## Project Structure

- `index.html` — App entry HTML
- `package.json` — Project metadata and scripts
- `vite.config.js` — Vite configuration
- `src/` — Source files
  - `main.jsx` — App bootstrap
  - `App.jsx` — Root component
  - `App.css`, `index.css` — Styles
  - `components/` — Reusable components (Header, Footer)
